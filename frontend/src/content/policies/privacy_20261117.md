# Whateat 개인정보 처리방침

**winning-ash**(이하 “운영자”)는 **Whateat**(이하 “서비스”)의 회원과 비회원의 개인정보를 다음과 같이 처리합니다.

## 1. 처리 정보·목적·보유기간

카카오 로그인, 이용자의 검색·저장 요청 및 문의를 통해 정보를 제공받거나 서비스 이용 과정에서 생성합니다.

| 구분 | 처리 정보와 목적 | 보유·이용기간 |
| --- | --- | --- |
| 회원 관리 | 카카오 사용자 식별번호·닉네임, 내부 회원 식별번호, 가입·수정 시각으로 계정 관리 | 회원탈퇴 완료 시까지 |
| 로그인 인증 | 카카오 인가 코드·접근 토큰으로 인증 및 사용자 정보 조회 | 로그인 처리 중 메모리에서 일시 이용 |
| 로그인 유지 | 세션 식별값·해시값, 회원 식별번호·만료 시각으로 로그인 유지 | 발급 후 7일간 유효. 로그아웃 시 해당 세션, 탈퇴 시 모든 세션 삭제 |
| 인증 요청 검증 | 보안 값·해시값·만료 시각으로 로그인 요청 검증 | 10분간 유효. 검증에 사용한 DB 정보는 삭제 |
| 회원 개인 목록 | 회원·음식점·목록 식별번호, 음식점·목록 이름, 등록 시각·소속 목록으로 좋아요·제외 목록 관리 | 직접 삭제하거나 회원탈퇴를 완료할 때까지 |
| 검색·추천 | 검색 중심 좌표, 반경·카테고리, 제외 음식점 식별번호, 로그인 세션 정보로 주변 음식점 추천 | 서버의 요청 처리 중 이용. 격자 위치·반경은 아래 캐시 기간 적용 |
| 공용 검색 캐시 | 격자 위치·검색 반경, 음식점 식별번호·이름·주소·좌표·카테고리·URL, 저장·만료 시각으로 검색 결과 재사용 | 저장 후 1시간 동안 유효. 저장 개수 제한에 따라 먼저 삭제될 수 있음 |
| 문의·권리 행사 | 이메일 주소·문의 내용·제공 자료의 개인정보로 답변 및 요청 처리 | 처리 완료 시까지. 진행 중인 분쟁은 종결 시까지 |

서비스 제공에 필요한 처리는 개인정보 보호법 제15조 제1항 제4호의 계약 체결·이행, 법정 권리 행사 처리는 같은 항 제2호의 법적 의무 이행을 근거로 합니다.

비회원도 검색·추천과 브라우저 내 목록 저장을 이용할 수 있습니다. 가입 정보를 제공하지 않으면 계정 기반 기능 이용이 제한될 수 있습니다. 검색 위치는 현재 위치 또는 지도에서 선택할 수 있습니다.

## 2. 쿠키와 브라우저 저장공간

| 구분 | 저장 정보·목적 | 보관기간 |
| --- | --- | --- |
| 로그인 쿠키 | 세션 식별값으로 로그인 유지 | 발급 후 7일. 정상 로그아웃·탈퇴 시 해당 브라우저에서 삭제 |
| 로그인 확인 쿠키 | 보안 값으로 로그인 요청 검증 | 최대 10분. 로그인 콜백 처리 시 삭제 |
| 비회원 개인 목록 | 목록 식별번호·이름과 음식점 식별번호·이름·등록 시각·상세정보로 좋아요·제외 목록 관리 | 직접 삭제하거나 사이트 데이터 삭제 시까지. 저장 개수 제한에 따라 이전 항목 제거 가능 |
| 임시 제외 목록 | 음식점 식별번호·이름·등록 및 만료 시각으로 추천 제외 | 2시간 동안 적용. 목록 조회 또는 화면의 만료 처리 시 삭제 |
| 화면 설정 | 테마·핀 색상·사용자 지정 색상 저장 | 설정 변경 시 갱신. 사이트 데이터 삭제 시 제거 |
| 로그인 결과 확인정보 | 탭의 세션 저장공간에 로그인 시도 여부를 저장하여 결과 알림 표시 | 로그인 상태 확인 처리 후 삭제. 남은 정보는 탭 세션 종료 시 정리 |
| 룰렛 기록 | 음식점 식별번호·이름·URL, 기록 식별번호·생성 시각을 화면 메모리에 보관 | 최근 20개. 새로고침 또는 해당 화면 종료 시 초기화 |

쿠키·사이트 데이터는 브라우저 설정에서 허용·차단·삭제할 수 있습니다. 차단·삭제하면 로그인 유지, 저장 목록 및 설정 기능이 제한되거나 초기화될 수 있습니다.

## 3. 파기 절차와 방법

처리 목적 달성이나 보유기간 종료 시 삭제 대상 정보를 확인하여 지체 없이 파기합니다. 세션·인증 요청 확인정보·캐시는 만료 시 사용을 중단하며, DB 자동 삭제 작업까지 시간 차이가 발생할 수 있습니다.

전자파일은 복구·재생되지 않도록 삭제합니다. 법령상 보존 의무가 있는 정보는 해당 기간 동안 다른 정보와 구분하여 보관한 후 파기합니다.

## 4. 카카오 연동

카카오 로그인 시 인가 코드·토큰·로그인 보안 값을 주고받고, 카카오에서 사용자 식별번호와 닉네임을 받습니다. 탈퇴 시에는 서버에서 카카오로 사용자 식별번호를 전달하여 서비스 연결을 해제합니다.

지도 표시·장소 검색 시 브라우저에서 카카오로 지도 영역·중심 좌표·검색어를 전달합니다. 주변 음식점 추천 시 서버에서 카카오로 중심 좌표·반경 또는 분할 검색 영역 등 검색 조건을 전달합니다.

## 5. 개인정보 처리업무의 위탁

| 수탁자 | 위탁업무 및 처리 정보 |
| --- | --- |
| Render Services, Inc. | 서버·웹사이트 호스팅. 회원정보·인증정보·개인 목록·검색 요청 등 서버에서 처리하는 정보 |
| MongoDB Limited (MongoDB Atlas) | 데이터베이스 호스팅·관리. 회원정보·로그인 세션·인증 요청 확인정보·개인 목록·공용 검색 캐시 |

MongoDB Atlas의 Cluster0는 대한민국의 AWS 서울 리전(ap-northeast-2)에 데이터를 저장합니다. MongoDB는 Amazon Web Services, Inc.의 클라우드 인프라를 이용합니다.

## 6. 개인정보의 국외 이전

서비스 서버는 미국 Oregon에 있습니다. 이용자의 요청 정보와 서울 데이터베이스의 정보는 미국 서버에서 조회·처리됩니다.

MongoDB Atlas의 데이터 저장 위치는 대한민국이며, 해외 관계사의 기술 지원이나 국외 처리를 수반하는 선택 기능을 이용하는 경우에는 관련 정보가 해외로 전달되거나 해외에서 조회될 수 있습니다. 아래 MongoDB 항목은 이러한 기능·지원 이용 시 적용되는 이전 범위를 안내합니다.

이전 범위가 변경되면 처리방침을 갱신하고 필요한 고지·동의 절차를 이행합니다.

## 7. 이용자의 권리와 행사 방법

이용자는 본인 또는 법정대리인·위임받은 대리인을 통해 열람, 정정·삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 목록 수정·삭제와 탈퇴는 서비스 내 기능으로, 그 밖의 요청은 제9항 연락처로 접수할 수 있습니다.

운영자는 필요한 범위에서 본인·대리인 여부를 확인하고 법정 기한 내에 결과를 안내합니다. 제한·거절 시에는 사유와 이의 제기 방법을 안내합니다. 위치 접근 권한과 브라우저 저장 데이터는 브라우저·기기 설정에서 관리할 수 있습니다.

## 8. 안전성 확보조치

세션·인증 요청 확인용 보안 값은 해시하여 DB에 저장합니다. HTTPS 통신과 인증 쿠키의 스크립트 접근 제한을 적용하고, 인증정보의 만료 여부와 회원별 접근 권한을 확인합니다.
